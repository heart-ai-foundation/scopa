# Support

SCOPA is a free open-source project maintained by Heart AI Foundation.

## Documentation and questions

Start with:

- [Quickstart](docs/QUICKSTART.md)
- [Slice-definition reference](docs/SLICE_DEFINITION.md)
- [Integration guide](docs/INTEGRATIONS.md)
- [Troubleshooting](docs/TROUBLESHOOTING.md)
- [Claims and non-claims](docs/CLAIMS.md)

For a reproducible non-security defect, open a GitHub issue using the bug
template. For a bounded enhancement, use the feature template and explain the
developer problem before proposing an interface.

## Security and privacy

Do not use a public issue for a suspected vulnerability, leaked credential,
private evidence, or customer data. Follow [SECURITY.md](SECURITY.md).

## Support boundary

Community support is best-effort. The public project does not include an SLA,
production operations, incident response for customer systems, or formal
compliance advice. Paid consultation may cover profiles, governance
installation, evidence review, and regulated integration, but verification of
SCOPA evidence remains independently available. When the need spans multiple
repositories, teams, or authority owners, read the
[optional organizational review](docs/ORGANIZATIONAL_REVIEW.md) and use the
[Heart AI Foundation contact route](https://empathyethicist.ai/contact/) to
discuss a private engagement. SCOPA does not transmit contact or usage data.
