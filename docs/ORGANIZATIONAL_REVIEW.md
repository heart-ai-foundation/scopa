# Optional organizational workflow-boundary review

SCOPA's free result is complete before any consultation: the runtime,
Boundary Doctor, task bootstrap, Boundary Map, Boundary Card, demo, evidence
validation, and pull-request summary all work locally without an account,
telemetry, lead capture, hosted verifier, or paid truth source.

An optional organizational review can help when the challenge is no longer one
repository or one agent session—for example:

- comparing control boundaries across many repositories and teams;
- creating evidence-backed capability profiles for internal agent launchers;
- separating developer, security, platform, and release authority;
- placing SCOPA gates and exception handling into existing CI governance;
- reviewing evidence retention, privacy, and restart behavior; or
- training maintainers to interpret partial, unknown, and authority-required
  surfaces without turning them into a generic score.

A useful engagement should produce concrete, independently reviewable outputs:

- a portfolio of current Workflow Boundary Maps;
- a prioritized control-gap and bypass inventory;
- client-specific launcher and capability-profile recommendations;
- an operating playbook for scope, completion, exceptions, and evidence; and
- a validation plan that the organization can continue running without the
  consultant.

Start by running `scopa demo`, then use `scopa` and `scopa view` in a
representative non-sensitive repository. Share only privacy-minimized cards or
sanitized assessments; never send credentials, private prompts, raw gate
output, customer code, or unreviewed evidence.

Heart AI Foundation can provide this work, and organizations may use any
qualified advisor. The public project remains independently usable and
verifiable either way. To discuss a private Heart AI Foundation engagement,
use the [contact route](https://empathyethicist.ai/contact/). SCOPA sends no
usage data or lead information to that route. For the public support and
private-security boundaries, see [Support](../SUPPORT.md) and
[Security](../SECURITY.md).
