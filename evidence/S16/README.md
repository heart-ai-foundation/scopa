deterministic qualification artifacts. It contains no provider transcript,
credential, account identity, authorization header, private evidence path, or
production Codex result.

tests and the installed probe execute only the committed S16 fault client and
record `providerInvocations: 0`.

policy, four-scenario allowance, aggregate token bounds, private evidence
destination, and stop conditions receive separate explicit approval.
