## Why this exists

A fresh installed-package agent proved the public operating instructions could
finish on gate completion without inspecting the tracked-change qualification
that only `view` exposed. It also reproduced invisible untracked files,
machine-first assistant setup and malformed-request recovery, a non-self-
contained cold next action, ambiguous evidence-export write semantics, and a
badge grammar defect.

## Implemented result

The installed and generated agent protocols now require the JSON Boundary Card
after final check. Current Git observation separately counts tracked and
untracked files, classifies both against paths and non-goals, and excludes
SCOPA-owned state. Human terminal setup and recovery are concise; machine
envelopes remain canonical. Cold continuation is executable, evidence exports
disclose their boundary, and badge nouns agree with their counts.

Canonical completion and gate-only `canStop` did not change. Legacy cards stay
valid and state that untracked files were not assessed. Shareable output still
contains no changed path, non-goal text, prompt, gate output, credential,
private root, or raw Git output.
