## Where we are

SCOPA 0.3.0 is a public, provider-off-capable runtime with a truthful workflow
boundary map, a zero-state Boundary Doctor, a one-file agent entry, and
reproducible release evidence. The remaining gap is experiential: the first
use still exposes protocol concepts and machine-oriented output before giving
the developer a concrete insight. The next phase keeps the same control and
truth boundaries while making the first useful result immediate, the task
journey genuinely one-prompt, and the useful result naturally shareable.

## Trajectory check

**Original goal:** provide a free runtime that lets developers map and enforce
the control boundaries of coding-agent work while creating an honest path to
deeper workflow-boundary consultation.

**Current direction:** preserve SCOPA's enforcement and evidence semantics,
but invert the adoption journey from protocol-first to insight-first. The
developer should receive a useful repository-specific boundary finding before
learning SCOPA vocabulary, then be able to begin a governed task with one
prompt and no hand-authored policy files.

**Drift assessment:** ACCEPTABLE. This is a principal-directed product-layer
correction toward the original open-source adoption and consultation purpose;
it does not change the kernel's assurance claims.
