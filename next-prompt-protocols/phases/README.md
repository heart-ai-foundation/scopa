# Phases

Per-phase READMEs are derived state, regenerated by `tools/sync-protocols.mjs` (and its `--rotate` mode) from the active protocol. Do not edit `phases/<phase>/README.md` by hand.

The phase directory used by `sync-protocols.mjs` is the first two dash-segments of the manifest's `current_phase` (e.g. `phase-1-foundation` → `phases/phase-1/`). When a phase advances, update `manifest.current_phase` and the script regenerates the matching `phases/<dir>/README.md` accordingly.

Add real phase entries below as the project grows.
