# S33 adversarial usability decisions

- Missing capability evidence is structural: neither an authority declaration
  nor a caller-supplied status can relabel an unevidenced surface as controlled.
- Human-readable output remains a digest-bound projection of the same canonical
  map used by JSON consumers.
- The point-and-go promise is one agent entry plus one developer task. Policy
  files, map inputs, and runtime commands are agent-owned setup details.
- A successful bounded run remains partial when native tool routes bypass
  SCOPA. The public journey states this instead of translating success into a
  general safety claim.
- Package documentation references resolve from both the package root and the
  referencing document. Missing references still fail candidate qualification.
- Gate examples use argv arrays. Shell-composed command strings are not taught
  as valid slice definitions.
- Provider-backed outside-model evaluation remained closed and was not needed
  to satisfy WBM5; the approved deterministic installed and adversarial checks
  directly exercised the claimed surface.
- Recommendation: accept the S29-S33 implementation for maintainer review and
  future release planning. Do not publish these changed bytes without a
  separately authorized versioned release qualification.
