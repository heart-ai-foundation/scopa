# SCOPA workflow boundary map

This package projects validated SCOPA policy, completion, capability, and
authority inputs into the closed `scopa.workflow-boundary-map.v1` contract.

The projection is pure and deterministic. It performs no filesystem, process,
network, or mutation effects and never treats missing capability evidence as a
safe default.

The public JSON Schema is
[`schemas/scopa.workflow-boundary-map.v1.schema.json`](../../schemas/scopa.workflow-boundary-map.v1.schema.json).
